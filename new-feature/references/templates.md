# 템플릿

## 리서치 결과 제안 형식

Phase 1.4에서 사용자에게 조사 결과를 제안할 때 아래 형식을 따른다.

```
## 리서치 결과

### 접근 방식
- [권장 접근 방식과 근거]

### 재사용할 기존 코드
- [파일:라인 — 설명]

### 외부 참고사항
- [조사에서 발견한 best practice]

### 예상 변경 범위
- [수정/생성할 파일 목록]
```

---

## 작업 완료 보고 형식

Phase 4에서 사용자에게 작업 결과를 보고할 때 아래 형식을 따른다.

```
## 작업 완료 보고

### 구현 내용
- [핵심 변경사항 요약]

### 변경 파일
| 파일 | 변경 유형 | 설명 |
|------|---------|------|
| `path/file` | 생성/수정 | 설명 |

### 검증 결과
- [검토에서 확인/수정한 사항]

### 추가 필요 작업
- [있다면 후속 작업 안내]
- [없으면 "없음"]

### 테스트 방법
- [사용자가 직접 확인할 수 있는 방법]
```
